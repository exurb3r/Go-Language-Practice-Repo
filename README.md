# Go Backend Playground

A repository dedicated to learning and experimenting with **Go (Golang), PostgreSQL, and Docker**, primarily focused on backend development and services.

This repository serves as a collection of Go projects, exercises, experiments, and practical implementations rather than a single standalone application.

## Technologies

- **Go** – Backend development and programming fundamentals
- **PostgreSQL** – Relational database management
- **Docker** – Containerization and development environments
- **Angular** – Potential frontend integration for future projects

## Repository Goals

- Strengthen programming fundamentals and problem-solving using Go.
- Learn backend architecture, REST APIs, and server-side development.
- Practice database design, queries, and PostgreSQL integration.
- Understand Docker and containerized development.
- Build small projects and gradually explore more complex applications.

## Projects

This repository will contain multiple projects as I progress, each exploring different concepts, tools, and implementations.

## Status

**Ongoing** — A personal learning and experimentation repository. Expect continuous additions, refactoring, and improvements.
